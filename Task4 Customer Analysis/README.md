# Task 4: Customer Data Analysis

## 🎯 Objective
Analyze customer purchasing behavior, segment customers, and identify the most valuable groups.

## 📊 Dataset
Mall Customer Segmentation Dataset
- 200 customers
- Columns: CustomerID, Gender, Age, Annual Income, Spending Score

## 🔍 Analysis Performed

### 1. Data Inspection
- Checked shape, data types, missing values
- Generated descriptive statistics

### 2. Customer Segmentation
- **By Age:** Young, Adult, Middle-Age, Senior
- **By Gender:** Male vs Female
- **By Income & Spending:** Scatter analysis

### 3. Key Findings
- Gender distribution: Female majority
- Average age, income, spending calculated
- Income vs Spending relationship analyzed
- Age group spending patterns identified

### 4. Most Valuable Customer Groups
- High income + high spending customers = most valuable
- Age groups with highest spending scores identified
- Gender-based income differences analyzed

## 📈 Visualizations
- Gender distribution (pie chart)
- Age distribution (histogram)
- Income vs Spending (scatter plot)
- Avg spending by age group (bar chart)
- Avg income by gender (bar chart)
- Combined dashboard

## 💡 Bonus: Marketing Strategies
1. **High spenders:** Loyalty programs, exclusive offers
2. **Young customers:** Social media campaigns
3. **Middle-age customers:** Premium products
4. **Female customers:** Targeted promotions
5. **High income group:** Personalized recommendations

Python, Pandas, Matplotlib, Seaborn, Jupyter Notebook
